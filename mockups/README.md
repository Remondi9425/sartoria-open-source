exist to argue about a layout, not to run.

- `back-office-console.html` — the internal console: sessions, agent traces,
  cost and latency per run. Open it in a browser directly.

directory and lost; only its renders survive, in `../ui-renders/`:

- `app-cliente-7-schermate.png`
- `app-cliente-scelta-e-checkout.png`
- `app-cliente-taglia-e-feedback.png`

wanted as working code, it gets rebuilt as a real Next.js front end rather
than resurrected as another static page.
